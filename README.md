## Global Energy Consumption Analysis


🔍 Problem Statement:
 With increasing global focus on sustainability and energy efficiency, analyzing patterns in energy production, consumption, and emissions is crucial. This project simulates a global energy database using SQL, enabling deep insights into energy usage, GDP correlation, population impact, and emission trends.



🎯 Project Goals:
Design and implement a normalized relational database representing global energy data.
Perform data analysis through advanced SQL queries.
Understand the relationship between energy consumption, GDP, population, and CO₂ emissions.
Practice complex joins, subqueries, aggregations, and ER modeling.




🛠️ Database Objects Used:
Tables: Country, Production, Consumption, Emissions, AVG.
Tools Used: MySQL, MySQL Workbench, Excel (for data preparation and transformation).
